# VirtualWorks Task 05 – ICSR Processing

## Overview

This project demonstrates a simulated Individual Case Safety Report (ICSR) processing workflow based on the general workflow covered in the VirtualWorks pharmacovigilance training material.

The exercise focuses on how a safety case moves from initial intake through data entry, assessment, quality review, medical review, and reporting classification.

> **Note:** This is a fictional training case created for educational purposes. It does not represent a real patient or a real regulatory submission.

## Simulated Case

- **Case ID:** VW-T5-001
- **Patient:** 45-year-old female
- **Reporter:** Treating physician
- **Suspect drug:** Diclofenac 50 mg tablets
- **Indication:** Acute musculoskeletal pain
- **Adverse event:** Upper gastrointestinal bleeding (melena)
- **Therapy start:** 08-Aug-2026
- **Event onset:** 14-Aug-2026
- **Therapy stop:** 14-Aug-2026
- **Outcome:** Recovered
- **Dechallenge:** Positive
- **Seriousness:** Serious – hospitalization
- **Severity:** Severe
- **Causality:** Probable
- **Reporting category:** 15-day

## Case Assessment

The case was assessed using the chronology and information provided in the simulated dataset. The causality assessment considers the temporal relationship between diclofenac exposure and the event, the known association between NSAID exposure and gastrointestinal bleeding, the positive dechallenge, and the absence of a stronger alternative explanation within the constructed case.

The seriousness classification is based on hospitalization. Severity refers to the intensity of the event and is kept separate from seriousness in the case assessment.

The 15-day reporting category is a training classification based on the reporting timelines described in the tutorial used for this exercise. It should not be interpreted as jurisdiction-specific regulatory advice.

## ICSR Workflow Demonstrated

1. **Case intake / triage** – checking whether the minimum information required for a valid case is available.
2. **Data entry** – entering patient, reporter, drug, event, treatment, and outcome information.
3. **Coding and narrative preparation** – organizing the case information and preparing a concise clinical narrative.
4. **Quality review** – checking the entered information for completeness, consistency, and accuracy.
5. **Medical review** – reviewing seriousness, causality, and the overall clinical assessment.
6. **Submission classification** – determining the appropriate reporting category for the simulated exercise.
